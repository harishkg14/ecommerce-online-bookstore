# E-Commerce Online Bookstore & Delivery Engine

## Project Overview
An online bookstore developed as an MBA Technology for Management project.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- InfinityFree Hosting

## Customer Features
- User Registration and Login
- Browse and Search Books
- Shopping Cart
- Checkout
- Order History

## Admin Features
- Admin Dashboard
- Book Management
- User Management
- Order Management
- Payment Records
- Delivery Management
- DSS Dashboard

## Database
The project uses MySQL with nine related tables:
Customers, Categories, Books, Carts, Cart_Items,
Orders, Order_Items, Payments and Deliveries.

## Decision Support System
- Cart Abandonment Rate
- Average Customer Lifetime Value
- Total Revenue
- Total Orders
- Top-Selling Books

## Deployment
Hosted using InfinityFree.

Note: Payment processing is simulated.
